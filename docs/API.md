# API and CLI

The public root exports `Skill`, `Node`, `Workflow`, `Dataset`, `Limits`, `Policy`, `Store`, `Optimizer`, model/context adapters, registry construction and `run_skill`. `contracts.Case`, `evaluation.Evaluator`, `selection.frontier/route`, `registry.export_skill/import_skill/lookup`, and `reporting.write_report` provide the remaining explicit boundaries. JSON schemas are in [schemas.json](schemas.json), generated by the installed CLI.

| Command | Purpose |
| --- | --- |
| `demo --directory PATH` | Complete authored offline run, freeze, final test, export and inspector |
| `fixture PATH` | Write authored dataset and seed JSON |
| `schemas [--output FILE]` | Export schema definitions |
| `run --database DB [--factory MODULE:FUNCTION] [--seed FILE] [--limits FILE] [--generate-seed]` | Start a persisted study |
| `resume --database DB --study ID [--factory ...] [--recover]` | Continue checkpoints; never silently repeat unresolved proposals |
| `discard-proposal --database DB --study ID [--factory ...]` | Explicitly abandon an unresolved proposal; retain reservations |
| `freeze --database DB --study ID [--factory ...]` | Prevent further search in a stopped study |
| `test --database DB --study ID [--factory ...] [--recover]` | Final evaluation of frozen champion; completed result is reused |
| `report` or `inspect --database DB --study ID --output DIRECTORY [--factory ...]` | Source-free report and local inspector |
| `export --database DB --study ID --output FILE [--factory ...]` | Frozen champion bundle and companion SKILL.md |
| `import FILE --database DB` | Verify/store a bundle with built-in operators; no promotion |
| `lookup FAMILY --database DB --context-hash HASH` | Compatible imported bundle provenance |
| `execute FILE --input JSON_FILE --database DB [--factory ...]` | Execute a portable bundle without dataset labels |

`run` does not freeze or open the test partition. Search returns the last eligible champion and a stop reason such as `proposer_exhausted`, `patience_exhausted`, `budget_exhausted`, `deadline_exceeded`, or `no_valid_skill`. Invalid candidates are recorded and bounded by candidate/patience limits. A deadline or cap during evaluation cannot promote partial evidence.

`freeze` rejects active/no-champion studies. A completed `test` returns the existing immutable report without additional calls. A partial test can resume exact missing cases only, within the original study limits. Search never resumes after freeze. Opening a new study after inspecting a final test is a new experiment and requires fresh test data for any generalization claim.

Bundles include skill instructions, graph, operator versions, context requirements, applicability family, lineage, validation evidence and optional final-test evidence. Hashes detect accidental mutation; they are not digital signatures or independent verification of imported scores. Import does not create a local champion. Execution checks current implementation, operator and context identity.

`frontier` requires complete eligible summaries from one comparison identity and family. It maximizes quality and minimizes calls/latency, optionally monetary cost. Epsilon bins, archive cap and deterministic tie breaking are explicit. `route` filters family/quality/call constraints and selects the caller's priority, or returns `None`. It rejects incomparable evidence rather than ranking unrelated experiments.
