# Project working instructions

Before project work, read these files in order:

1. `docs/README.md`
2. `docs/RULES.md`
3. `docs/MEMORY.md`
4. The relevant milestone in `docs/IMPLEMENTATION_PLAN.md` and tasks in `docs/TASKS.md`.

Follow the rules within the user's authorized scope. The implementation plan describes intended work; verify code and evidence before marking tasks complete. Record task progress in `docs/TASKS.md` and durable decisions, evidence, and handoff context in `docs/MEMORY.md`.

The supplied conversation in `context/` is local history and excluded from Git. Preserve it without rewriting it. Do not commit the context directory or its integrity receipt.

Do not create subagents unless the user or a later applicable instruction explicitly authorizes delegation.
